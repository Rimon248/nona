# Виртуальный Помощник Нона

Ранний кроссплатформенный VPN-клиент. Flutter-приложение входит через отдельный Keycloak Ноны, регистрирует устройство и проверяет подписанные обновления. Android-служба использует Xray-core. Пользователь может зарегистрироваться сам, затем администратор разрешает ему VPN-доступ в панели. Выдача индивидуальных данных доступа запускается сервером после разрешения. Секреты, ссылки подписки и сертификаты в репозиторий не включены.
