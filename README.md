# Виртуальный Помощник Нона

Ранний каркас кроссплатформенного VPN-клиента. Сейчас репозиторий содержит Flutter-приложение для Android, iOS, Windows и macOS, серверный вход в аккаунт, проверку и защищённое локальное хранение подписанных обновлений, а также проектные документы. **VPN-соединение и вход в аккаунт в клиенте пока не реализованы.** Никакие действующие ключи, ссылки подписки или сертификаты не включены.

## Состав

- `apps/client` — общий интерфейс Flutter, проверка подписанных конфигураций, защищённое хранение и чистая логика выбора узла.
- `services/control-api` — сервер аккаунтов и сессий с PostgreSQL. По умолчанию слушает только `127.0.0.1:8080`; выдача конфигураций отключена.
- `docs/architecture.md` — компоненты, безопасность и границы возможностей ОС.
- `docs/mvp.md` — этапы реализации и критерии приёмки.
- `docs/api.md` — планируемый контракт аккаунтов и выдачи конфигураций.
- `docs/backend.md` — запуск аккаунтов на домашнем сервере.
- `docs/privacy-and-threats.md` — видимость VPN и границы защиты от других приложений.
- `test-vectors` — общий вымышленный пакет для проверки совместимости Go и Flutter.

## Локальный запуск

```sh
cd apps/client
flutter run
```

```sh
cd services/control-api
go test ./...
go run ./cmd/api
```

Публиковать API в интернет пока нельзя: защищённая выдача конфигураций и регистрация устройств ещё не написаны. Для домашнего сервера потребуется HTTPS reverse proxy, постоянный адрес или домен и продуманное поведение при недоступности дома. Порядок настройки аккаунтов — в `docs/backend.md`.
