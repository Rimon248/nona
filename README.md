# Виртуальный Помощник Нона

Ранний кроссплатформенный VPN-клиент. Flutter-приложение входит через отдельный Keycloak Ноны, регистрирует устройство и проверяет подписанные обновления. Android-служба использует Xray-core. Hysteria2 и VLESS+REALITY ранее работали на тестовом телефоне через VDSina, но 10 ноября 2026 года повторная проверка подключения завершилась таймаутом обоих протоколов; текущая доступность VPN не подтверждена. Кнопка отключения закрывает системный VPN-интерфейс. При активном подключении доступна ручная проверка задержки HTTPS через туннель. Пользователь может зарегистрироваться сам, затем администратор разрешает ему VPN-доступ в панели. Выдача индивидуальных данных доступа запускается сервером после разрешения. Секреты, ссылки подписки и сертификаты в репозиторий не включены.

## Состав

- `apps/client` — общий интерфейс Flutter, вход в аккаунт, регистрация устройства, проверка подписанных конфигураций, защищённое хранение, выбор узла, экран выбора прямых приложений Android и нативная Xray-служба Android.
- `services/control-api` — API аккаунтов, устройств и пакетов конфигурации с PostgreSQL и проверкой токенов отдельного Keycloak. Закрытая служба администратора применяет решения о доступе и периодически создаёт либо отзывает данные доступа на VDSina.
- `docs/architecture.md` — компоненты, безопасность и границы возможностей ОС.
- `docs/engine-choice.md` — проверка ядер Happ/v2rayN/v2rayNG и выбор Xray плюс Hysteria 2 для Ноны.
- `docs/mvp.md` — этапы реализации и критерии приёмки.
- `docs/api.md` — действующие маршруты аккаунтов и выдачи заранее установленных конфигураций.
- `docs/backend.md` — запуск аккаунтов на домашнем сервере.
- `deploy/home` — Docker-размещение для существующего Caddy на домашнем сервере, отдельный домен и проверки перед публикацией.
- `docs/publication.md` — фактическое состояние публичного HTTPS, отдельного Keycloak и панели.
- `docs/credential-encryption.md` — формат шифрования данных доступа для устройства.
- `docs/privacy-and-threats.md` — видимость VPN и границы защиты от других приложений.
- `docs/app-routing.md` — что видно приложению при прямом и VPN-маршруте.
- `test-vectors` — вымышленные пакеты подписи и шифрования для проверки совместимости Go и Flutter.
- `third_party` — происхождение Android-библиотеки Xray и тексты лицензий.

## Локальный запуск

```sh
cd apps/client
flutter run
```

Для тестовой Android-сборки запускайте `apps/client/build-android-debug.sh`: он задаёт HTTPS-адрес и закреплённый публичный ключ проверки подписанных конфигураций из `apps/client/trust/nona-config-2026-11.b64`. Публичный HTTPS и вход через Keycloak на тестовом Android уже проверены. Сборка без этого ключа не принимает обновления. Пароли, токены, закрытый ключ подписи и IP VPN-узла в параметры сборки не добавляйте.

Один аккаунт может использовать несколько устройств. После входа каждое устройство автоматически регистрирует свой ключ и получает отдельные VPN credentials; пользователь не копирует ссылки. Это позволяет отключить потерянное устройство без замены ключей на остальных. Общий ключ на весь аккаунт был бы проще на сервере, но не позволил бы выборочно отзывать доступ.

```sh
cd services/control-api
go test ./...
go run ./cmd/api
```

Отдельные Keycloak и API опубликованы через домашний Caddy. Панель доступна пользователям с ролью администратора: она показывает состояние служб, список пользователей и позволяет разрешать или отзывать VPN-доступ. Только исходный администратор `roman` может назначать других администраторов. При подключении Android пробует Hysteria2, затем VLESS на каждом узле из подписанного пакета. Автоматическое переключение при обрыве уже работающего туннеля и другие серверы ещё не реализованы. Подробности — в `docs/publication.md`.
