# Локальный запуск аккаунтов

Сейчас backend может создавать аккаунты и обслуживать вход, обновление токенов и выход. Выдача VPN-конфигураций, регистрация устройства и провижининг VDSina ещё выключены. Это не публичный сервис до настройки HTTPS, секретов, резервного копирования и проверки на домашнем сервере.

Требуются Go 1.26+, PostgreSQL 14+ и доступ через локальный socket либо TLS с проверкой сертификата. Не передавайте пароль базы в командной строке и не коммитьте его. Для запуска задайте `NONA_DATABASE_URL` в защищённой конфигурации сервиса. HTTP-сервер с аккаунтами разрешает слушать только loopback; снаружи нужен HTTPS reverse proxy, который ограничивает запросы и не записывает тела входа и ответы с токенами в логи.

1. Создайте отдельную базу и роль с минимально нужными правами.
2. Примените `sql/001_accounts.sql` через `psql` с `ON_ERROR_STOP=1`.
3. В терминале запустите `go run ./cmd/admin create-user ИМЯ`. Команда спросит пароль без отображения. Публичной регистрации нет.
4. Запустите `go run ./cmd/api` с `NONA_DATABASE_URL`. Без этой переменной сервер отдаёт только `/healthz` и `/v1/info`.

API: `POST /v1/sessions` (`username`, `password`), `POST /v1/sessions/refresh` (`refresh_token`), `DELETE /v1/sessions/current` с `Authorization: Bearer <access_token>`. Access token действует 15 минут, refresh token — до 30 дней и вращается, абсолютный срок сессии — 90 дней. В БД сохраняются только SHA-256 дайджесты случайных токенов. Пароли хешируются Argon2id с уникальной солью (64 MiB, 3 прохода, 1 поток). Повтор использованного refresh token отзывает сессию. Лимит попыток в приложении: 5 на имя за 5 минут и 30 глобально за минуту, максимум две параллельные проверки пароля. На reverse proxy нужен дополнительный лимит, поскольку лимиты процесса обнуляются при перезапуске.

Следующие обязательные работы до реального использования: вход в Flutter-клиент, регистрация и отзыв устройств, шифрование индивидуальных credentials для устройства, выдача пакетов, миграции при обновлении схемы, резервное копирование и восстановление, мониторинг, настройки HTTPS и проверка угроз на домашнем сервере.
