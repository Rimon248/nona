## Решение для Ноны

Основное ядро — **Xray-core** для VLESS+REALITY. Это общая подтверждённая основа Happ и v2rayNG и одно из ядер v2rayN. Для Hysteria2 на первом этапе используем **официальный Hysteria 2 core** отдельным транспортом: v2rayN тоже поддерживает его отдельно. Современная документация Xray описывает совместимый Hysteria v2 transport, но совместимость с уже работающим сервером пользователя и мобильной сборкой ещё не проверена; перевод Hysteria2 на один Xray можно делать только после такого теста.

В репозитории `engine_profiles.dart` готовит конфигурации для обоих ядер в памяти. Клиент не записывает их в обычные настройки, не показывает их в UI и не содержит реальных адресов или credentials. Тестовую конфигурацию VLESS+REALITY без рабочих секретов проверил официальный Xray-core 26.11.9 командой `xray run -test`: `Configuration OK`. Официальный Hysteria 2 v2.13.0 также прочитал тестовую конфигурацию и вывел share URI. Бинарники сверены с опубликованными SHA-256 и оставлены вне репозитория. Эти проверки подтверждают формат, а не соединение с реальным сервером. Выбор транспорта в пакете конфигурации будет указывать, какому ядру передать настройки. Если один модуль недоступен, переключение не должно молча отправлять трафик напрямую.

Нативный запуск ещё не реализован. На Android понадобится `VpnService`, передача TUN в локальный сетевой слой и защита сокета подключения от петли через `protect()`. Для Apple нужен Packet Tunnel extension, для Windows — системный TUN/adapter. Сервис не должен открывать VPN-интерфейс до готовности рабочего ядра. Проверка конфигураций на реальных версиях ядер и устройствах обязательна до подключения.

Лицензии исходных проектов различаются: [Xray-core — MPL-2.0](https://github.com/XTLS/Xray-core/blob/main/LICENSE), [официальный Hysteria 2 — MIT](https://github.com/HyNetworks/hysteria/blob/master/LICENSE.md), [libXray wrapper — MIT](https://github.com/XTLS/libXray), а [v2rayN](https://github.com/2dust/v2rayN) и [v2rayNG](https://github.com/2dust/v2rayNG) — GPL-3.0. Поэтому Нона использует ядра и собственный код интеграции, а не копирует код этих приложений. Перед распространением бинарников нужно выполнить требования лицензий всех включённых зависимостей.

## Что проверить следующим

1. Получить исходники или APK RefLab VPN и установить точный состав движков конкретной сборки; текущий README этих сведений не содержит.
2. Собрать и проверить конкретные версии Xray и Hysteria 2 на тестовых конфигурациях без рабочих секретов.
3. Подключить нативные процессы/библиотеки и системный TUN на Android; проверить прямые приложения, DNS, IPv6 и переключение при отказе.
4. Затем выпустить индивидуальные зашифрованные credentials с домашнего сервера и проверить их на отдельном тестовом устройстве.
