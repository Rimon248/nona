# Настольная Нона: пробная TUN-сборка

На Windows и macOS Нона входит через тот же аккаунт, проверяет подписанную конфигурацию устройства и пробует Hysteria2, затем VLESS+REALITY на каждом выданном узле. Десктопный режим использует системный TUN Xray. Режим системного прокси запланирован после iOS. Раздел «Интернет без VPN» с исключением отдельных приложений пока работает только на Android; настольный TUN направляет в VPN весь интернет-трафик, кроме частных адресов локальной сети. Автоматическое переключение после обрыва уже установленного соединения ещё не готово.

## macOS

`apps/client/build-macos-release.sh` загружает проверенную по SHA-256 универсальную сборку Xray и создаёт `apps/client/build/macos/Build/Products/Release/Nona.app`. Нона запрашивает пароль администратора только при запуске или остановке TUN: Xray создаёт `utun`, а Нона временно задаёт системные DNS-серверы и возвращает прежние при отключении. Закрытие окна оставляет приложение и соединение работающими; щелчок по значку в Dock вновь открывает окно. Команда «Выход» сначала отключает VPN. Если процесс был аварийно закрыт, снова откройте Нону и нажмите «Отключить», чтобы восстановить DNS.

Apple Developer Program для этой локальной TUN-сборки не требуется. Приложение подписывается локальной ad-hoc подписью, поэтому macOS может запросить ручное разрешение на запуск загруженного архива. Для распространения с обычной проверкой Gatekeeper позднее понадобится Developer ID и нотариализация. Данные аккаунта и подписанные пакеты хранятся в Keychain без возможности общего доступа с другими приложениями.

## Windows

`apps/client/build-windows-release.ps1` загружает libXray, Xray-core и Wintun с проверкой SHA-256 и создаёт папку `apps/client/build/windows/x64/runner/Release`. Распространять и переносить нужно **всю папку**, а не один `.exe`. Windows запрашивает повышение прав при запуске Ноны, поскольку TUN меняет системные маршруты и правила Windows Filtering Platform. Закрытие окна оставляет Нону в области уведомлений; пункт «Отключить VPN и выйти» останавливает соединение.

Проверка «пинга» измеряет время HTTPS-ответа через активный TUN, а не ICMP до VPN-сервера. Начальная проверка соединения может не пройти, если узел или тестовый HTTPS-сайт недоступны.

## Получение пробных сборок

После успешного запуска GitHub Actions **Desktop preview** скачайте артефакт нужной системы со страницы запуска. Эти архивы пока не являются выпуском GitHub Release. На Mac проверьте вход и подключение на этом компьютере; на Windows используйте ваш ноутбук или Parallels. Перед публикацией для остальных пользователей нужны успешная сборка, проверка реального трафика и отключения на обеих системах.
