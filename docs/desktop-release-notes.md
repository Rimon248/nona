# Установка настольной Ноны

Это ранний выпуск Ноны для Windows 11 x64 и macOS Intel/Apple Silicon. VPN-подключение требует прав администратора, потому что Нона создаёт системный туннель и меняет маршруты.

## Windows

Скачайте и распакуйте `nona-v<версия>-windows.zip`, затем запустите `nona_client.exe` из распакованной папки. Переносить нужно всю папку. Windows может показать предупреждение SmartScreen, поскольку эта ранняя сборка пока не подписана сертификатом издателя.

## macOS

Скачайте и распакуйте `nona-v<версия>-macos.zip`, затем переместите `Nona.app` в «Программы». Подпись раннего архива зависит от настроенного в GitHub сертификата. Если он не нотариализован Apple, при первом запуске macOS может потребовать разрешить его открытие в настройках безопасности.

Для macOS-архива требуется постоянная Apple-issued подпись через секреты GitHub Actions `NONA_MACOS_CERT_P12_BASE64` и `NONA_MACOS_CERT_PASSWORD`. На macOS 13+ после установки приложения в «Программы» разрешите системный помощник на экране аккаунта и в настройках «Объекты входа и расширения». Подключение и отключение затем не запрашивают пароль администратора. Для публичного распространения необходимы Developer ID и нотариализация.

## Проверка файлов

Вместе с каждым архивом публикуется файл `.sha256`. На Mac проверяйте его командой `shasum -a 256 -c <имя-архива>.sha256`, на Windows — `Get-FileHash <имя-архива> -Algorithm SHA256` и сравните значение с опубликованным файлом.
