# Установка настольной Ноны

Это ранний выпуск Ноны для Windows 11 x64 и macOS Intel/Apple Silicon. VPN-подключение требует прав администратора, потому что Нона создаёт системный туннель и меняет маршруты.

## Windows

Скачайте и распакуйте `nona-desktop-v<версия>-windows.zip`, затем запустите `nona_client.exe` из распакованной папки. Переносить нужно всю папку. Windows может показать предупреждение SmartScreen, поскольку эта ранняя сборка пока не подписана сертификатом издателя.

## macOS

Скачайте и распакуйте `nona-desktop-v<версия>-macos.zip`, затем переместите `Nona.app` в «Программы». Этот архив ad-hoc подписан и не нотариализован Apple: при первом запуске macOS может потребовать разрешить его открытие в настройках безопасности. Для такого выпуска Apple Developer ID не подключён.

Из-за ad-hoc подписи macOS не регистрирует встроенный LaunchDaemon-помощник. Поэтому подключение и отключение VPN может продолжать запрашивать пароль администратора. Обычная подпись Developer ID и нотариализация нужны для выпуска, который macOS сможет открыть без ручного разрешения; эта настройка требует Apple Developer Program.

## Проверка файлов

Вместе с каждым архивом публикуется файл `.sha256`. На Mac проверяйте его командой `shasum -a 256 -c <имя-архива>.sha256`, на Windows — `Get-FileHash <имя-архива> -Algorithm SHA256` и сравните значение с опубликованным файлом.
